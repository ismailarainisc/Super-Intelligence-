# UI previews

Captured from the running RC8 mobile web interface in Chromium at 430 × 932 CSS pixels (2× scale). A read-only adapter supplies source-build defaults; native actions, Android capture and AI responses are not simulated. These are browser UI previews, not device or Gemini verification. The neutral M avatar is the actual fallback when private character assets are absent.

Reproduce with `scripts/capture-readme-previews.cjs`; see its comments for the browser prerequisites.
